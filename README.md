# Credit Risk Prediction API

A production-style machine learning credit risk prediction service built with **Python, FastAPI, LightGBM, Docker, and AWS ECS**.

The API exposes a REST endpoint that accepts borrower attributes and returns the probability of default generated by a trained machine learning model.

This project demonstrates an end-to-end machine learning lifecycle:

- Data preparation and model training
- Credit risk modeling
- Model serialization
- API development
- Unit testing
- Docker containerization
- Cloud deployment architecture

---

# Project Overview

Credit risk models are used by financial institutions to estimate the likelihood that a borrower will default on a loan.

This project implements a binary classification model that predicts:

\[
P(Default \mid Borrower\ Attributes)
\]

The prediction service allows downstream applications to integrate credit risk scoring through a REST API.

# Model Development

The credit risk model uses a gradient boosting classification approach.

## Model

**Algorithm**
LightGBM Classifier


## Example Features

The model accepts borrower-level attributes such as:

| Feature | Description |
|---|---|
| income | Annual borrower income |
| fico | Credit score |
| loan_amount | Requested loan amount |
| age | Borrower age |
| debt | Existing debt obligation |
| employment | Employment history |
| balance | Account balance |
| utilization | Credit utilization |
| accounts | Number of credit accounts |
| history | Credit history length |

# Running Locally

## 1. Clone Repository

```bash
git clone <repository-url>

cd credit-risk-api

2. Install Dependencies
pip install -r requirements.txt

3. Start API Server
uvicorn app.main:app --reload

API Start: http://localhost:8000

Doc - http://localhost:8000/redoc

API Endpoints
Health Check
Request
GET /health
Response
{
    "status": "healthy"
}
Credit Risk Prediction
Request
POST /predict

Example request:

{
    "income": 90000,
    "fico": 750,
    "loan_amount": 10000,
    "age": 45,
    "debt": 5000,
    "employment": 10,
    "balance": 15000,
    "utilization": 0.15,
    "accounts": 8,
    "history": 15
}

Example response:

{
    "default_probability": 0.12
}

The response represents the predicted probability of default.
